# Changelog

## 0.1.0 — 2026-11-18

First publication package of the v5 raised-fan prototype. Includes STL, editable P1S PETG 3MF, inherited interface/author sources, geometry generation and verification, support toolpaths, three actual v5 print photographs, v4 reference installation photo, and documentation. Final v5 installation and thermal checks remain pending.

Added the preliminary v2/v4 airflow comparison, velocity maps and numerical evidence to explain the design changes. The published v5 remains explicitly outside the simulated comparison.
